Команды для запуска проекта VotingSystem
=========================================

Требования:
- Установленный .NET SDK 9.0 или новее
  (проверить: dotnet --list-sdks)

Запуск:
1. Перейти в папку проекта:
   cd VotingSystem-master\VotingSystem-master

2. Собрать проект (проверка ошибок):
   dotnet build

3. Запустить проект (профиль http):
   dotnet run --launch-profile http

После запуска приложение доступно по адресу:
   http://localhost:5062

Остановка:
- Нажмите Ctrl+C в окне, где запущено приложение.

Примечание:
- Профиль запуска задан в файле Properties\launchSettings.json
- Имя БД: app.db (SQLite), создается/обновляется автоматически при первом запуске
